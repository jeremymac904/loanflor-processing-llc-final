# Investor and specialty programs

Use `<investor-id>/<program-id>/` for Jumbo, Non-QM, DSCR, Bank Statement, Asset Depletion, Investor Cash Flow, Foreign National, ITIN, alternative documentation and lender-specific specialty programs. These are product categories, not universal rules. Require the actual approved investor/lender guide and exact version before calculations or eligibility answers. Missing guide returns SOURCE_GAP.
