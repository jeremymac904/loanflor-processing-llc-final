# Platform Sources

## Hermes Agent

- Repo: https://github.com/NousResearch/hermes-agent
- Bot Mode: https://hermes-agent.nousresearch.com/docs/user-guide/bot-mode
- Desktop: https://hermes-agent.nousresearch.com/docs/user-guide/desktop
- Baseline release: v0.21.0 / tag `v2026.8.31`

Bot Mode is a UI over Hermes profiles. Profiles isolate config, memory, skills, credentials, and chat history.

## Zapier MCP

- https://zapier.com/mcp

Zapier MCP exposes scoped actions/searches to MCP-compatible agents. Flo should scope actions per specialist and re-apply Flo's own deterministic policy.

## Unsloth

- https://unsloth.ai/

Unsloth Desktop/Studio supports local model running/training and an OpenAI-compatible API, and it documents connecting agents such as Hermes/Codex/OpenCode/Claude through `unsloth start`.
