# Source Library

## Included

`owner_supplied/originals/` contains the source material supplied for Ashley/Flo.

`official/` contains source registries and official URLs.

## Not bundled

This pack does not republish entire Fannie/Freddie/agency guide libraries.

Reasons:
- guides change frequently;
- effective dates matter;
- some materials have owner-specific redistribution terms;
- production should use an approved, versioned private source cache instead of a stale ZIP snapshot.

## Build requirement

Codex should create the source-ingestion architecture and source registry now, but only activate rules after approved source ingestion and regression testing.
