# Ashley Approval Center

All Yellow actions should arrive in one queue regardless of which bot proposed them.

Each approval card should show:

- proposing bot;
- loan/workspace if applicable;
- action;
- recipient/destination;
- summary/purpose;
- attachments/data categories;
- exact draft or payload preview;
- source/context;
- expiry;
- Approve;
- Edit;
- Reject.

Approval must bind to the exact action payload. Material edits create a new approval request.

Examples:
- Whisper -> send borrower email;
- Chadwick -> place title order;
- Franklin -> publish GBP post;
- Flo -> update an external system.

A specialist should never tell Ashley "I sent it" when the action is only proposed.
