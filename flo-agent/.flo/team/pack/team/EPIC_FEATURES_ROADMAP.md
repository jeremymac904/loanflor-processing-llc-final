# Epic Features Roadmap

These features make the system feel like a real operating team rather than a collection of chats.

## 1. Team Floor
Live roster with current assignment, waiting state, routine, and attention flag.

## 2. Loan Deal Rooms
One workspace per file with relevant specialists automatically invited by milestone/task.

## 3. File Readiness Score
Malcolm produces a transparent readiness score based on missing docs, discrepancies, AUS status, income/assets completion, and unresolved questions. Never make the score an approval decision.

## 4. Guideline Cards
Sage outputs a compact source card:
- program;
- topic;
- source;
- section;
- published/effective date;
- overlay;
- conclusion;
- confidence.

## 5. Calculation Workbench
Deterministic income/assets calculations with visible inputs and formulas.

## 6. Approval Center
One place for outbound email, orders, uploads, publishing, and other side effects.

## 7. Knowledge Freshness Monitor
Sage periodically checks official source metadata and flags new versions as "pending review" instead of silently changing production rules.

## 8. Agent Health / Cost Panel
Track:
- local vs cloud runs;
- response time;
- Zapier MCP task usage;
- tool failures;
- model fallback;
- context size;
- source freshness.

## 9. Shadow Mode
Run bots against synthetic or historical-redacted scenarios before granting external actions.

## 10. Pipeline Heat Map
Flo shows:
- today;
- at risk;
- waiting;
- blocked;
- closing pressure;
- fastest wins.

## 11. Post-UW Feedback Loop
Compare Sage/Malcolm prep findings with actual UW conditions. Propose process improvements without turning file-specific conditions into universal rules.

## 12. Marketing Content Factory
Franklin maintains:
- content pillars;
- editorial calendar;
- newsletter queue;
- social variants;
- GBP queue;
- blog queue;
- approval status;
- performance notes.

## 13. Privacy Zones
Marketing is structurally denied borrower folders. Processing bots only see assigned loan workspaces. Sensitive integrations are capability-scoped.

## 14. Synthetic Mortgage Eval Lab
A library of fake loan files tests calculations, routing, prompt injection, source conflicts, missing-doc detection, and handoffs before updates ship.

## 15. Model Bench
Use local Unsloth for suitable private/repetitive work and approved cloud models for higher-complexity tasks, with per-task routing and fallback.
