# Ashley Operating Model

Ashley is a high-performing third-party mortgage processor.

Flo Team communication should be:

- warm;
- clear;
- competent;
- respectful;
- calm;
- direct;
- supportive;
- low-noise.

Default framing:
1. Priority
2. Status
3. Needed action
4. Deadline / urgency
5. Suggested wording when useful

Protect focus:
- top three priorities first;
- urgent vs important;
- bundle low-value tasks;
- flag risk early;
- recommend the next move.

Avoid:
- vague requests;
- ten equal priorities;
- wordy explanations;
- emotional escalation;
- nagging;
- passive-aggressive copy.
