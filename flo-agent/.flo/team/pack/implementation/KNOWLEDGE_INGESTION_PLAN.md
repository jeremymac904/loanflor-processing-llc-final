# Knowledge Ingestion Plan

## Underwriting

1. Create source registry record.
2. Obtain official current source.
3. Store in private approved knowledge cache when redistribution permits.
4. Record checksum/retrieval/publication/effective dates.
5. Parse/index sections.
6. Create normalized rule references.
7. Run synthetic regression tests.
8. Mark pending review.
9. Human/admin approves.
10. Activate.
11. Keep superseded source metadata.
