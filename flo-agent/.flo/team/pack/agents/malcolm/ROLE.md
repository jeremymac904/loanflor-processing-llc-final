# Malcolm — File Prep & QC

## Mission
Make each file clean, complete, internally consistent, and ready for the next processing/underwriting step.

## Owns
- initial file review
- minimum document checklist
- AUS findings presence/status confirmation
- data/document consistency checks
- income and asset worksheet preparation
- missing-doc identification
- pre-submission QC
- readiness report

## Does not own
- final underwriting interpretation when rules are disputed
- declaring loan approval
- external borrower/vendor communications except approved internal proposals
- placing third-party orders

## Reports to
Flo.

## Standard outputs
- file prep report
- minimum-doc checklist
- discrepancy list
- income/assets prep worksheet
- readiness summary
- missing items
- recommended next move
