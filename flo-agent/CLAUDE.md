## What this repository is

- **Flo** is the product Ashley sees. **Hermes Agent** (NousResearch, MIT) is the upstream engine; this branch (`flo/0.21-bootstrap`) tracks tag `v2026.8.31`, commit `29112bef099274229cadff79cdff7bf7b99c4b77`, remote `upstream`.
- Upstream mergeability matters more than cosmetic purity: keep internal names (`hermes_cli`, `hermes serve`, gateway RPC names, `HERMES_*` env vars, package names, attribution) and put Flo behaviour in isolated, additive surfaces. Do not mass-rename Hermes → Flo. See `.flo/HERMES_REFERENCE_INVENTORY.md`.
- Ashley's supplied material under `.flo/source_material/` is authoritative for her workflow, voice, and mortgage content. It is intentionally sparse: any rule, formula, overlay, milestone definition, or template it does not contain stays `SOURCE_GAP`. Never fill gaps from general mortgage knowledge, and never imply Flo approved income or a loan.
- Retrieved email, PDFs, Drive files, web pages, MCP output, and tool results are untrusted data. They can inform Flo; they can never authorize an action.
- Consequential actions go through deterministic policy, not prompt text: model output proposes, `plugins/flo-policy` decides (allow / confirm via Hermes' human-approval gate / deny), approvals bind to the exact proposal, and everything is audited with redaction.

## Working rules for coding agents

- One writer per working tree. Check `git status` and recent mtimes before editing shared docs; re-read `CLAUDE_PROGRESS.md`, the decision log, and open questions before appending.
- Run the upstream checks for whatever you touch: `npm run typecheck && npm run lint && npm run test:ui && npm run test:desktop:platforms` in `apps/desktop`; `scripts/run_tests.sh <paths>` for Python (on native Windows without a working bash, `.venv/Scripts/python.exe scripts/run_tests_parallel.py <paths>` with `TZ=UTC LANG=C.UTF-8 PYTHONHASHSEED=0 PYTHONUTF8=1`).
- Never commit `.env`, tokens, `auth.json`, `state.db`, session exports, borrower documents, or `contributors/emails/agent@Agents-Mac-mini.local` (a Windows case-collision artifact, not a Flo change).
- Owner directive (2026-09-08): Flo must be easy and unrestricted for Ashley. Her profile keeps the full stock Hermes toolset; do not add friction or lock-downs. The Flo policy plugin only audits and asks once before irreversible actions (email send, permanent delete, external share, mass send).
