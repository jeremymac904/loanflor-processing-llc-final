# Ashley's Flo Setup

## Before you start
Your PC needs **two things** installed by you, one-time:
1. **Docker Desktop** — open `https://www.docker.com/products/docker-desktop/` in your browser, click Download, run the installer, **restart your PC** when it asks.
2. **Ollama** — open `https://ollama.com/download` in your browser, click Download for Windows, run the installer.

That's the only technical setup. Flo handles everything else.

## Install Flo
1. **Unzip `Flo-0.17.0-win-x64-portable.zip`** — right-click → Extract All → pick a folder you'll remember (e.g., `Desktop\Flo`).
2. **Double-click `Flo.exe`** inside that folder.

   > If Windows shows "Windows protected your PC", click **More info → Run anyway**.

## First-run onboarding
Flo opens to a welcome screen. Click through each card. Flo does the work for you:

3. **Connect Google** — click the card, a browser window opens, sign in, click Allow, paste the code Flo shows back into Flo.
4. **Connect Gmail** — click the card, enter your Gmail address + the App Password (from `myaccount.google.com/apppasswords`), click Save.
5. **Connect Zapier** *(optional)* — paste your Zap webhook URL, click Save.
6. **Set Up Local Signing** — click the card. If Docker isn't running, Flo will offer to start it for you. Flo waits for Docker, then brings up the signing service. Shows **Ready** when done.
7. **Set Up Local AI** — click the card. Flo checks for Ollama, offers to install it if needed, then downloads a small AI model. Shows **Ready** when done.

## Enter Flo
8. Click **Continue**. You're in Flo.
