Flo 0.18.1

This small maintenance update verifies Flo's in-app update experience. It includes the current integrated Flo shell and runtime from the canonical branch.

Ashley-friendly changes:
- Flo can check GitHub Releases for updates from Settings → About.
- Your local files, connections, settings, and conversations remain in your Windows user profile during app updates.

Technical:
- Windows x64 NSIS installer and electron-updater metadata are attached.
- macOS public update assets require configured Apple Developer signing and notarization.
